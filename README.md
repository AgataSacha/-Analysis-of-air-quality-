Aby wykorzystać wstawione pliki, należy zrobić tak, jak jest wyjaśnione tutaj: https://www.youtube.com/watch?v=_ynMa2XlRgk 
albo po ogarnięciu gita na kompie można w bash wpisać git clone *klucz skopiowany z githuba*.
Następnie utwórz wirtualne środowisko, czyli wciśnij Ctrl+Shift+P, wpisz "Python: Create Environment", wybierz "Venv", a następnie wskaż interpreter Pythona.
W pliku requirements.txt znajdują się potrzebne do zanstalowania biblioteki. Aby to uruchomić, należy w wierszu poleceń wpisać pip install -r requirements.txt
Uwaga! Nie używaj do niczego power shella, tylko bash lub command line
